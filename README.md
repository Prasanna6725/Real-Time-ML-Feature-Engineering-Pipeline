# Real-Time ML Feature Engineering Pipeline

This project builds a containerized, production-style streaming feature pipeline with Kafka, a Flink-based processing job, a real-time producer, and a dashboard that consumes feature updates live.

## Services

- `zookeeper` and `kafka` provide the event bus.
- `producer` simulates user interactions and publishes `user-events` and `content-metadata`.
- `flink-jobmanager` runs the streaming feature pipeline, computes windowed features, and writes to `feature-store`.
- `flink-taskmanager` is a companion service required by the evaluation contract.
- `dashboard` consumes `feature-store` and `pipeline-metrics` and exposes a live UI.

## Quick Start

1. Copy `.env.example` to `.env` if you want to override any defaults.
2. Start the stack:

```bash
docker compose up --build -d
```

3. Open the dashboard at `http://localhost:8501`.

## Topics

- `user-events`: raw user interaction stream with at least 3 partitions.
- `content-metadata`: compacted lookup topic keyed by `content_id`.
- `feature-store`: compacted feature sink keyed by `entity_id:feature_name`.
- `pipeline-metrics`: operational metrics consumed by the dashboard.

## Required IDs for Evaluation

The repository includes `submission.json` with stable IDs generated by the producer:

- `test_user_id`: `user_001`
- `test_content_id`: `content_001`

## Batch Comparison

The producer writes raw events to `./artifacts/generated_events.jsonl` and metadata to `./artifacts/generated_metadata.jsonl`. Run the batch comparison script to recompute the same features offline:

```bash
python scripts/batch_analysis.py --events artifacts/generated_events.jsonl --metadata artifacts/generated_metadata.jsonl
```

## Notes

- All timestamps are ISO 8601 with `Z` suffix.
- Late events are deliberately generated and are older than the 30-second watermark tolerance but still within the required 35-90 second range for validation.
- The Flink job computes user tumbling-window features, content sliding-window features, and category affinity features enriched from content metadata.
